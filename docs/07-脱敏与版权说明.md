## 2. 截图规范

界面截图是作品集里最容易泄露信息的部分。每一张都要过一遍：

- [ ] 数据全部为**虚构 mock**，不使用生产数据脱敏后截图（脱敏不彻底是常见事故）；
- [ ] 地址栏、浏览器书签、开发者工具、系统托盘全部裁掉或遮挡；
- [ ] 页面右上角账号名、头像、团队名替换为虚构值；
- [ ] 二维码替换为占位图（真实群二维码可被扫码加入）；
- [ ] 图片素材使用占位图，不使用真实活动照片；
- [ ] 不展示任何证件照、身份证号、完整手机号（中间四位打码也不够，直接换号）；
- [ ] 不展示真实快递单号；
- [ ] 导出文件截图（Excel）同样需要替换数据；
- [ ] 图片元数据（EXIF）清空。

**推荐做法**：搭一套纯 mock 数据（3 个渠道、6 个观影团、4 个项目、20 条申请），专门用于截图。这套数据本身也可以作为「演示数据脚本」放进作品集。

> `demo/` 下的可运行原型已经内置了一套虚构数据，直接用它截图即可，不需要碰生产库。
