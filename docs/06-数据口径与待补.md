# 06 · 数据口径与待补

> **原则：没有真实数据的指标，宁可不写。** 这一页是给自己用的填数模板，不是对外展示的内容。
> 所有数字必须来自生产库的**只读导出**，注明时间窗口，并排除测试账号与测试项目。

---

## 1. 北极星指标

**有效履约申请数** = 已发货 且 已完成返图评分的申请数。

选它的理由：它同时约束了三件事——渠道方真的发了、团长真的办了、成果真的回收了。只看「申请数」会奖励刷单，只看「注册数」会奖励拉人，都不代表业务跑通。

## 3. 漏斗

```
浏览公开项目
   ↓
完成认证（影迷 → 观影团）
   ↓
获得渠道准入（标签 / 邀请码 / 手动添加）
   ↓
提交申请
   ↓
审核通过
   ↓
发货
   ↓
提交返图
   ↓
完成评分
```

每一层的转化率对应一个产品问题：

| 掉在哪一层 | 说明什么 | 该动哪里 |
|---|---|---|
| 浏览 → 认证 | 认证门槛或材料说明有问题 | 认证表单、材料示例 |
| 认证 → 准入 | 渠道方拉人不足 | 邀请码、按手机号添加 |
| 准入 → 申请 | 项目信息或报名窗口有问题 | 项目详情、报名时间 |
| 申请 → 通过 | 团长填错，或渠道方审得太严 | 预填、字段必填规则 |
| 通过 → 发货 | 渠道方操作成本高 | 批量发货、模板 |
| 发货 → 返图 | 履约提醒不足 | 订阅消息、返图入口 |
| 返图 → 完成 | 渠道方没评分 | 评分入口、批量评分 |

## 4. 填写规范

1. **时间窗口**：注明统计区间（如「2026-10-01 至 2026-10-31」），不要用「累计」而不写截止日期。
2. **排除项**：测试账号、测试项目、内部演示数据必须排除，并在脚注说明。
3. **分母**：比率类指标必须写明分母口径（按申请数还是按项目数）。
4. **中位数优先**：时长类指标用中位数，均值容易被个别极端值带偏。
5. **没有就不写**：系统没采集的（如退件率），不要用「约」「大概」填充。

---

## 5. 回填到简历 / 作品集的建议

| 场景 | 建议写什么 | 建议不写什么 |
|---|---|---|
| 简历一行 | 「覆盖 X 家渠道、Y 个观影团，累计 Z 单申请，返图率 W%」 | 「提升了 XX% 效率」这类无基线对比的表述 |
| 作品集 | 指标 + 口径 + 时间窗口 + 一句结论 | 单点最高值（如「单项目最高 300 单」） |
| 面试口述 | 先说口径，再说数字，最后说这个数字说明什么 | 只报数字不说口径 |

**没有基线就没有百分比。** 如果要做前后对比（如「退件率从 A 降到 B」），必须有改造前的台账数据；没有的话，只描述改造后的绝对值。
